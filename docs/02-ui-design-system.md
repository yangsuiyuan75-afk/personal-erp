# 02. 统一 UI 设计系统

## 1. 视觉方向

现代 SaaS 后台，但避免纯黑、纯白、全灰的单调设计。

默认主题：**Iris Operations**

整体感受：

- 清晰；
- 稳定；
- 有层级；
- 适合长时间查看数据；
- 色彩用于导航、重点和状态，不用于大面积噪声。

## 3. 深色模式

支持浅色、深色、跟随系统。

默认浅色。

深色背景使用深蓝紫灰，不使用
`#000000`。深色主题仍保留紫色、青绿和琥珀状态色。

## 4. 页面布局

```text
左侧 Sidebar：240px，可折叠至 72px
顶部 Header：56px
主内容区：模块内滚动
页面最大宽度：自适应，不强制窄容器
```

外层页面不得出现横向滚动；宽表格在表格容器内滚动。

## 5. 导航

导航分组：

- 工作台
- 商品中心
- 库存中心
- 采购管理
- 销售管理
- 质量管理
- 财务管理
- 系统设置

一级菜单使用图标和文字。二级菜单使用手风琴展开。

当前模块使用紫色高亮条和淡紫背景。

## 6. 列表页统一结构

```text
页面标题 + 页面说明 + 主操作
统计摘要（可选）
查询筛选栏
批量操作栏
DataTable
分页器
```

筛选栏采用浅色卡片，不使用全屏大表单。

- 筛选栏使用紧凑控件；桌面端控件最小高度 34px，搜索框需完整展示占位提示；
- 所有按钮文字不换行；Select 触发器的已选值不得撑开容器，超长时省略显示；下拉选项可换行并完整展示。

日期范围筛选直接显示在筛选栏，统一使用中文 Ant Design `DatePicker.RangePicker`，不收进“更多筛选”。

## 7. 表格

统一 `DataTable` 支持：

- 服务端分页；
- 多字段筛选；
- 关键字查询；
- 服务端排序；
- 当前页全选；
- 批量操作；
- 列显示设置；
- 查看详情 Dialog；
- 固定操作列；
- Loading Skeleton；
- Empty State；
- Error State；
- URL 状态恢复。

默认详情必须使用中文字段名；嵌套对象或数组按独立分区展示，不得把原始 JSON、技术字段名或超长值混排在普通字段网格中。
详情只展示当前业务视图需要的字段；数据库 UUID、幂等键、版本号和关联外键不进入用户弹窗，关联主数据统一显示“业务编号 · 名称”。
所有面向用户的枚举值必须展示中文名称，英文代码只用于接口和数据库值。
业务单据表格必须将业务数量和“SKU 编码 · SKU 名称”作为可见列；包含多个 SKU 时逐行完整展示，数量按明细汇总。

表头使用带轻微紫灰背景，不使用纯灰。

状态列使用语义 Badge：

- 正常/已完成：青绿；
- 草稿：灰蓝；
- 待处理：琥珀；
- 失败/不良/报废：红色；
- 处理中：蓝色；
- 已停用：中性灰。

## 8. 表单

- 2 列桌面布局，窄屏 1 列；
- 必填字段明确；
- 所有单选和多选使用 shadcn/ui Base UI Select，禁止显示原生下拉框；
- 所有可编辑文本输入框、文本域和日期选择组件关闭浏览器自动填充；
- 所有日期展示和选择均精确到日，使用中文 Ant Design `DatePicker`；月份筛选精确到月，不展示或录入时分秒；
- 键值属性使用可增删的“属性名 / 属性值”行编辑器，不要求手写 JSON；
- 字段错误显示在字段下方；
- 保存按钮使用品牌紫；
- 危险操作单独分区；
- 长表单使用分区 Card；
- 长表单 Dialog 固定标题与底部操作栏，仅表单内容区滚动；滚动条使用品牌紫主题；
- 所有业务图片缩略图与详情图均可点击放大预览，并支持缩放；
- 图片加载期间显示动态加载指示，不以静态占位图伪装已加载；
- 新增弹窗关闭或取消后必须清空未提交内容；再次打开时仅显示默认值，编辑弹窗则按当前记录重新初始化；
- 表单离开时有未保存提示。

## 9. 弹窗策略

- 全局请求 Loading 必须 Portal 到 `body`，并使用最高层级，始终覆盖 Dialog、Alert Dialog 和其他浮层；
- 简单新增：Dialog；
- 快速编辑：Sheet；
- 表格常规详情：Dialog；
- 复杂单据：独立页面；
- 删除/停用/恢复：Alert Dialog；
- 详情信息较多：独立详情页，不使用超大弹窗。

## 11. 库存核心工作区

用户已选择 data-first 库存工作区作为主要视觉方向：

- 紧凑深海军蓝侧边栏；
- 单一大表格作为主工作面，不使用 KPI 卡片墙；
- 搜索、仓库、库存状态、类目和更多筛选位于统一工具栏；
- 选中 SKU 后在右侧上下文栏展示库存分布、成本、批次来源和推荐操作；
- 主要操作固定为“发起调拨”；
- 期初库存与库存调整收进次级“业务操作”菜单，避免与主操作争夺视觉层级；
- 1024 像素下侧边栏折叠为图标导航，390 像素下使用 60 像素导航、堆叠筛选和两列视图切换；
- 保持高信息密度，但不得牺牲行高、对比度和键盘可操作性。

## 12. 备份恢复工作区

- 延续 data-first 大表格、统一筛选栏与右侧上下文栏；
- 顶部只保留最近恢复点、业务过账阈值和维护状态三个安全指标；
- `VERIFIED` 使用青绿、处理中使用品牌紫、失败使用红色、过期使用中性灰；
- 恢复必须使用独立危险 Dialog，明确覆盖范围、PRE_RESTORE、SHA/Schema/计数检查；
- “创建保护点并恢复”只有密码非空且精确短语匹配后可用；
- Bootstrap 恢复入口仅在管理员创建页展开，不与常规管理员创建表单混淆。
