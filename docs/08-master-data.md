# 08. 基础资料模块

## 1. 类目

- 第一版单层类目；
- 名称允许重复，代码唯一；
- 已有 Product 引用时不可删除；
- 停用后新建/编辑 Product 不可选择；
- 已绑定 Product 继续显示原类目并标记已停用。

## 2. Product

- 绑定一个 Category；
- 可以没有 SKU；
- 没有 SKU 时不能发生交易；
- 支持多图；
- 主图最多一个；
- 图片排序可拖拽；
- 停用不影响历史业务。

## 3. SKU

- 绑定 Product；
- code 可更正且唯一；
- 基础单位必填；
- 不保存价格与成本；
- 属性通过键值对录入，如颜色、型号、规格。

## 4. Supplier

- 支持联系信息；
- 支持默认采购渠道；
- 支持质量问题统计；
- 支持应付余额统计；
- 停用后不能用于新采购，但历史保留。

## 5. Buyer

- 不是登录用户；
- 可关联多个采购渠道；
- 用于采购订单、价格历史和采购分析。

## 6. SalesChannel 与 Customer

分开管理。

SalesChannel 负责来源、库存模式和平台仓。

Customer 负责具体交易对象和协议价。
