# 00. 产品范围与成功标准

## 1. 产品定位

Personal ERP 是单用户、本地运行的仓库、渠道、质量和资金管理系统。

不是：

- 多租户 SaaS；
- 完整法定会计软件；
- 公网商城；
- 企业审批平台。

第一版必须能处理真实业务，而不是仅提供 CRUD。

## 2. 业务闭环

```text
产品资料
→ 采购报价与采购订单
→ 收货入库与移动平均成本
→ 仓库/渠道仓库存
→ 渠道或客户销售
→ 销售退货
→ 质量检查
→ 供应商索赔、换货、赔付或报废
→ 应收应付与实际收付款
→ 月度收入、支出、毛利和损失分析
```

## 4. 成功标准

系统必须能够完整录入以下示例：

1.  将 SKU A 从主仓调拨 20 个到 AliExpress 平台仓；
2.  AliExpress 售出 10 个；
3.  平台退仓 20 个进入待质检；
4.  质检结果：18 个良品、2 个供应商质量问题；
5.  18 个回到可售库存；
6.  2 个转为供应商索赔；
7.  供应商选择补发 2 个或赔付对应金额；
8.  财务和库存均形成可追溯流水；
9.  客户 A 以 20 元/个拿货 100 个；
10. 客户 A 退回 5 个损坏品，并完成责任判定和财务处理。
